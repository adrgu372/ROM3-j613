# ROM3-j613 stable-20261127.5

This snapshot separates the installed distribution from the upstream Aurora
package names and rebuilds the J613-specific stack under the ROM3 namespace:

```text
linux-rom3                  7.3.0.aurora1-46
linux-rom3-headers          7.3.0.aurora1-46
rom3                        1.0.0b17-2
rom3-userpages              7.3.0.aurora1-46
rom3-audio                  4.1.aurora2-12
rom3-boot                   20261018-21
rom3-firstboot              0.1.13-6
rom3-sep                    1-29
rom3-j613-control           1-2
rom3-j613-meta              1-13
rom3-j613-guard             1-12
rom3-firmware               20261018-7
rom3-j613-release           1-9
```

The snapshot also carries the renamed firmware, camera, keyboard-light,
Wi-Fi, secure-enclave, fingerprint, power, panel and graphics packages needed
by the image. The image consumes these exact signed artifacts and enables the
ROM3 repository before the first boot.

`rom3-j613-release` owns the persistent repository configuration and reapplies
the ROM3 identity (`NAME=ROM3`, `ID=rom3`, `VARIANT_ID=j613`) after filesystem
updates. `rom3-system-fixes` now depends on the ROM3 package aliases rather
than the old Aurora names.

Kernel `7.3.0.aurora1-46` retries transient `EBUSY` click waveforms during
resume and keeps host-driven trackpad feedback enabled for the next click
instead of falling back to firmware until reboot.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release
sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Run the live check after the next reboot:

```bash
sudo /usr/share/rom3-j613/verify-live-system.sh
```
