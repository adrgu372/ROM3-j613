# ROM3-j613 stable-20261124.1

> [!NOTE]
> This snapshot is superseded by `stable-20261124.2`, which pins the immutable
> repository tag instead of GitHub's cacheable `releases/latest/download`
> alias. The hardware package set is otherwise identical.

This snapshot promotes the J613 stack to:

```text
linux-aurora          7.3.0.aurora1-44
linux-aurora-headers  7.3.0.aurora1-44
aura                  1.0.0b17-1
aurora-userpages      7.3.0.aurora1-44
rom3-j613-meta        1-7
rom3-j613-guard       1-7
```

The kernel includes the upstream Apple SIO protocol-10 table-selection fix
needed by Aura b17. Aura includes the J613 card-idle mask fix; all 47 of its
audio scenarios pass.

Aura b17 automatically reserved the J613 external DCP with firmware 14.7. The
display driver then crashed the primary DCP with `axi_rd_err`, leaving a blank
screen. ROM3 now sets `chosen.asahi,t8122-dcpext=0` unless the owner explicitly
chooses another value. This keeps the internal panel stable.

The tested Stage 2 digest is:

```text
58e3a6da8f48e66bc97a862b891c66522c8587a5946a2ce2e123b32c391fa102
```

Live validation on `apple,j613` passed the panel, GPU, render node, audio,
camera and Vulkan checks.

## Update from stable-20261122.9

First install the new update guard. It fixes Btrfs snapshots when
`/swap/swapfile` is active:

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard
```

Then authenticate the signed override for the exact replacement versions:

```bash
sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261124.1 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Reboot after `--apply`, then run:

```bash
/usr/share/rom3-j613/verify-live-system.sh
```

Direct `pacman -Syu` remains unsupported for the protected hardware stack.
