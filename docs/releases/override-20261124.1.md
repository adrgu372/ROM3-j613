# ROM3-j613 override-20261124.1

This signed override updates systems based on `stable-20261122.9` to the
hardware stack in `stable-20261124.1`:

```text
aura                  1.0.0b17-1
aurora-userpages      7.3.0.aurora1-44
linux-aurora          7.3.0.aurora1-44
linux-aurora-headers  7.3.0.aurora1-44
rom3-j613-guard       1-7
rom3-j613-meta        1-7
```

The GitHub release is marked as a prerelease only so it cannot replace the
stable snapshot behind `releases/latest/download`. The packages and repository
database are fully signed and qualified for this exact update.

The new guard recreates an independent Btrfs swapfile around the pre-update
snapshot, so systems with an active `/swap/swapfile` can update normally.

Install the guard first:

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard
```

Then configure this immutable feed:

```bash
sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261124.1 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Reboot and run the live checks afterward.
