# ROM3-j613 stable-20261128.1

This snapshot carries the ROM3-namespace image stack and the first update
tooling refresh built entirely without Aurora package identifiers:

```text
linux-rom3                  7.3.0.aurora1-46
linux-rom3-headers          7.3.0.aurora1-46
rom3                        1.0.0b17-2
rom3-userpages              7.3.0.aurora1-46
rom3-audio                  4.1.aurora2-12
rom3-j613-control           1-3
rom3-j613-meta              1-14
rom3-j613-guard             1-13
rom3-firmware               20261018-7
rom3-j613-release           1-10
```

The Control Center has a modern card-based interface with persistent light
and dark themes, separate Updates, System and Activity pages, and themed
confirmation and error dialogs. All original maintenance actions remain
available.

Safe updates now run non-interactively and perform a storage preflight before
creating a snapshot. Insufficient free space and invalid swapfiles stop the
transaction with specific exit statuses and messages before packages change.

The GitHub release checker ignores old signed overrides that still contain
legacy `aura` or `aurora` package names. Until a ROM3-namespace override is
published, it reports that no compatible signed protected-package update is
available instead of configuring an unusable feed.

Kernel `7.3.0.aurora1-46` retains the bounded `EBUSY` retry for trackpad click
feedback after resume.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release
sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Run the live check after the next reboot:

```bash
sudo /usr/share/rom3-j613/verify-live-system.sh
```
