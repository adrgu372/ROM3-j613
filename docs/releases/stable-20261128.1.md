# ROM3-j613 stable-20261128.1

This snapshot refreshes the complete ROM3-namespace package stack and delivers
the first polished Control Center and update-safety release. Runtime package
ownership no longer depends on the legacy Aurora package names.

## Highlights

### Modern Control Center

`rom3-j613-control 1-3` replaces the previous single-page interface with:

- a sidebar for Updates, System and Activity;
- card-based update and diagnostics pages;
- persistent light and dark appearance selection;
- styled confirmation and failure dialogs;
- direct links for safe Arch updates, signed ROM3 releases and automation;
- automatic opening of the detailed activity log when an operation starts.

All previous maintenance actions remain available.

### Safer and fully automatic updates

`rom3-j613-guard 1-13` improves the update transaction:

- safe updates run with `pacman --noconfirm` and no longer wait for terminal
  confirmations;
- a storage preflight runs before any feed is configured or package is changed;
- insufficient space returns exit `75` with free-space, swapfile and reserve
  details;
- an empty, truncated or inactive swapfile returns exit `74`;
- the Control Center maps both statuses to specific warnings;
- swapfile recreation now uses a temporary file, so a failed allocation cannot
  destroy the active swapfile.

### Correct GitHub release discovery

The old signed `override-*` releases still contain `aura` and `aurora` package
names and are intentionally rejected by the ROM3-only validator. The updater
now detects that before configuring a feed.

When no compatible override exists, a check completes successfully with:

```text
No signed protected-package update is available.
```

It no longer fails after configuring an unusable repository.

### Trackpad haptic resilience

Kernel `7.3.0.aurora1-46` retries transient `EBUSY` click waveforms during
resume. If the actuator remains busy, host-driven feedback is kept enabled so
the next click can take it again instead of until reboot.

### Sensor and hardware stack

The image package set carries `iio-sensor-proxy-rom3`, which reports ambient
light colour temperature in addition to illuminance. The tested Apple J613
bootloader, Mesa/Vulkan, KWin, PipeWire, WirePlumber and speaker-safety stack
remain pinned.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release
sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Run the live check after the next reboot:

```bash
sudo /usr/share/rom3-j613/verify-live-system.sh
```
