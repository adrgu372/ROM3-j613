# ROM3-j613 override-20261126.2

This signed cumulative override updates systems based on
`stable-20261122.9` directly to the validated kernel 45 stack:

```text
aura                  1.0.0b17-1
linux-aurora          7.3.0.aurora1-45
linux-aurora-headers  7.3.0.aurora1-45
aurora-userpages      7.3.0.aurora1-45
rom3-j613-meta        1-8
rom3-j613-guard       1-8
rom3-j613-release     1-3
```

It was booted on J613 with macOS 27.2.1 and Apple system firmware 27.2.
The panel, GPU, Vulkan, camera and speaker-safety checks passed. Apple still
reports the J613 OS component firmware as 14.7 on this macOS release.

This release is marked as a prerelease only so it cannot replace the stable
snapshot behind `releases/latest/download`.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release

sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261126.2 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```
