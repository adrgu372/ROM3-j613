# ROM3-j613 KDE image payload 20261128.1

Filesystem payload for the Aurora Installer `alarm-btrfs-v1` layout, built only
for `apple,j613`, using package snapshot `stable-20261128.1`.

## What changed

### New ROM3 visual identity

The ROM3 penguin emblem is installed everywhere visible:

- desktop application icon;
- Places/start icon at every icon size;
- KDE About distribution logo;
- Plymouth boot splash.

The Plymouth and desktop logo files are byte-identical. No Aurora logo is used
as the visible system identity.

### Modern update application

`rom3-j613-control 1-3` includes:

- a sidebar with Updates, System and Activity pages;
- card-based layout with native Qt styling;
- persistent light and dark themes;
- themed dialogs and activity log;
- all original status, update, verification and automation actions.

### Better update behavior

`rom3-j613-guard 1-13` adds:

- non-interactive safe package updates;
- preflight checks before snapshots or package changes;
- specific exit codes and explanations for insufficient storage or an invalid
  swapfile;
- safer atomic swapfile recreation;
- filtering of obsolete signed overrides that still contain Aurora names.

### Hardware improvements

The image includes:

- `linux-rom3 7.3.0.aurora1-46` with the trackpad haptic resume retry;
- `iio-sensor-proxy-rom3` with ambient-light colour temperature;
- the tested Apple J613 Stage 2 set: 61 board payloads from 68 device trees;
- Mesa/Vulkan 26.3 development stack;
- PipeWire and WirePlumber 1.6.10 / 0.5.18;
- speakersafetyd and speakerguardd;
- ROM3 identity, repository configuration and update guard.

### ROM3-only package ownership

Runtime image packages are installed from the ROM3 namespace rather than
Aurora-owned names. The exact tested package set includes:

```text

linux-rom3-headers          7.3.0.aurora1-46

```

five parts:

```text
arch-kde-filesystems.tar.zst.part.02
arch-kde-filesystems.tar.zst.part.03
arch-kde-filesystems.tar.zst.part.04
```

The reconstructed filesystem archive has:

```text
SHA-256 3abdeb4aa2486b18dede3ee3d2758e82a0a5c96e673d9a4ab719ead162f75386
```

provenance is included as `arch-kde-filesystems.tar.zst.attestation.jsonl`.

## Reassemble and verify

```bash
tag=image-20261128.1
base=https://github.com/adrgu372/ROM3-j613/releases/download/$tag
mkdir -p rom3-j613-$tag
cd rom3-j613-$tag
curl -fLO "$base/reassemble-image-payload.sh"
curl -fLO "$base/arch-kde-payload.json"
curl -fLO "$base/SHA256SUMS"
curl -fLO "$base/SHA256SUMS.sig"
gpg --verify SHA256SUMS.sig SHA256SUMS
bash ./reassemble-image-payload.sh
```

Installer inputs:

```text
arch-kde-filesystems.tar.zst
arch-kde-image.json
```
