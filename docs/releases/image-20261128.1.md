# ROM3-j613 KDE image payload 20261128.1

Filesystem payload for the Aurora Installer `alarm-btrfs-v1` layout, built only
for `apple,j613`.

This image uses package snapshot `stable-20261128.1` and includes:

- `linux-rom3 7.3.0.aurora1-46` with the trackpad haptic resume retry;
- `rom3-j613-control 1-3` with the modern light/dark Control Center;
- `rom3-j613-guard 1-13` with storage preflight errors and non-interactive safe
  updates;
- the ROM3 penguin logo in desktop icons and Plymouth boot branding;
- `iio-sensor-proxy-rom3`, including ambient-light colour temperature;
- the complete ROM3 namespace without Aurora-owned runtime package names;
- the tested Mesa, Vulkan, PipeWire, WirePlumber, KWin and speaker-safety stack.

GitHub's release-asset limit requires the filesystem archive to be split into
parts under 2 GiB. `SHA256SUMS` is signed by the ROM3-j613 project key and the
archive's GitHub build provenance is included as an offline attestation.

This remains a testing image. It has not completed a new clean-install,
every-boot and Recovery qualification cycle on J613.
