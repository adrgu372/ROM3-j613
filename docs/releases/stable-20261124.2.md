## What changes for J613

ROM3 moved from Aura `1.0.0b14.1` directly to `1.0.0b17`, so this update also
includes the b15 and b16 work. The upstream b17 release itself is mainly an SIO
change; most of the larger display and firmware-27 support landed in b15.

| Area | Result on the current J613 stack |
| --- | --- |
| Internal panel | The full `2560x1664` panel surface and its ADT-described 64-row notch are exposed instead of cropping to `2560x1600`. |
| Brightness | The panel's maximum brightness is taken from the Mac's ADT rather than a fixed assumption. |
| SIO and kernel | Aura supplies both protocol-9 and protocol-10 SIO boot-table layouts; kernel 44 selects the layout reported by the running firmware. |
| Live DCP handoff | Loader-owned DCP buffers are protected and the live RTKit session is described before Linux takes ownership. Invalid state is refused instead of guessed. |
| External USB-C display | Aura b17 can hand over the M3 Air external DCP on macOS 27.2, but that path crashes the primary DCP with the current 14.7 firmware. ROM3 therefore keeps `chosen.asahi,t8122-dcpext=0`; external displays remain unsupported until this path is qualified on J613. |
| Firmware 27.2 readiness | M3 DCP, ISP, GPU and display handoff support for macOS 27.2 is included, but it is inactive on this 14.7 component firmware and is preparation for a future transition. |
| Audio | ROM3's J613 card-idle-mask patch is included in addition to upstream Aura. All 47 Aura audio scenarios pass and the live speaker-safety checks succeed. |
| General hardening | The release includes upstream fixes for AOP/DART access, video encoder handoff, PCIe, NVMe warm start, IOVA, ring buffers, ADT parsing and on-disk parsers. |

This is primarily a compatibility and reliability update. There are no broad
new desktop features; the immediately visible changes are the notch-aware
panel geometry and more accurate brightness metadata.

## Update from stable-20261122.9

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release

sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261124.2 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Reboot and run:

```bash
/usr/share/rom3-j613/verify-live-system.sh
```

Direct `pacman -Syu` remains unsupported for the protected hardware stack.
