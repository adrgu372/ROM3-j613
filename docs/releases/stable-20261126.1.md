# ROM3-j613 stable-20261126.1

This snapshot promotes the tested J613 stack to:

```text
linux-aurora          7.3.0.aurora1-45
linux-aurora-headers  7.3.0.aurora1-45
aura                  1.0.0b17-1
aurora-userpages      7.3.0.aurora1-45
rom3-j613-meta        1-8

```

Kernel 45 is built from Aurora Linux `release/7.3.0-41` at
`87a5f8f0e6e8e037a32aa0dc51a4a3bb06c29dd6`, with the same ROM3 T8122 PMP,
GPU map, MCA speaker-sense and Apple SIO protocol-10 patches used by kernel 44.

## Validation

The candidate was booted on `apple,j613` with:

```text
kernel                    7.3.0-1-45-ARCH
macOS                     27.2.1
Apple system firmware     27.2
Apple OS components       14.7
```

The panel, Apple M3 G15G GPU, Vulkan renderer, camera/AVD devices and
speaker-safety stack all passed. No DCP crash or DART translation fault was
observed. Apple keeps the J613 OS component firmware at 14.7 even with macOS
27.2.1, so Aura's 27.2 DCP path is not selected on this model.

```text

```

  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261126.2 \
