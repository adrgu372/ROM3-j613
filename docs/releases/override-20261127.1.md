# ROM3-j613 override-20261127.1

This cumulative signed override updates systems based on
`stable-20261122.9` directly to:

```text
aura                  1.0.0b17-1
linux-aurora          7.3.0.aurora1-45
linux-aurora-headers  7.3.0.aurora1-45
aurora-userpages      7.3.0.aurora1-45
rom3-j613-control     1-1
rom3-j613-meta        1-9
rom3-j613-guard       1-9
rom3-j613-release     1-4
```

It installs the graphical control center and the safe/approved update backend.
The helper always fetches immutable `override-YYYYMMDD.N` releases from the
fixed `adrgu372/ROM3-j613` repository and verifies them with the ROM3 signing
fingerprint.

This release is marked as a prerelease so it cannot replace the stable snapshot
behind `releases/latest/download`.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release

sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261127.1 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```
