# ROM3-j613 stable-20261127.1

This snapshot adds the graphical ROM3 Control Center to the tested J613
hardware stack:

```text
linux-aurora          7.3.0.aurora1-45
linux-aurora-headers  7.3.0.aurora1-45
aura                  1.0.0b17-1
aurora-userpages      7.3.0.aurora1-45
rom3-j613-control     1-1
rom3-j613-meta        1-9
rom3-j613-guard       1-9
rom3-j613-release     1-4
```

The Qt/Plasma application provides:

- current kernel, Aura and Apple firmware status;
- ordinary package updates with the entire protected stack held;
- signed ROM3 release discovery and installation from GitHub;
- automatic daily installation of the newest signed override;
- live-system verification and a complete activity log.

The updater offers separate safe and approved modes. Safe updates never consume
an override. Approved updates admit only exact protected versions covered by
the signed manifest and keep every other protected package pinned. Automatic
updates are disabled until the owner enables them in the GUI.

Hardware qualification remains the kernel 45 validation from
`stable-20261126.1`: J613, macOS 27.2.1, Apple system firmware 27.2, component
firmware 14.7, working panel, GPU, Vulkan, camera and speaker safety.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release

sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261127.1 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```
