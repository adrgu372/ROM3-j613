# ROM3-j613 override-20261124.2

This signed override updates systems based on `stable-20261122.9` to:

```text
aura                  1.0.0b17-1
aurora-userpages      7.3.0.aurora1-44
linux-aurora          7.3.0.aurora1-44
linux-aurora-headers  7.3.0.aurora1-44
rom3-j613-guard       1-7
rom3-j613-meta        1-7
rom3-j613-release     1-2
```

The guard recreates an independent Btrfs swapfile around the pre-update
snapshot. The release package replaces GitHub's cacheable `latest` alias with
the immutable `stable-20261124.2` repository URL.

The update also brings the full Aura b14.1-to-b17 delta: notch-aware
`2560x1664` panel handling, ADT brightness metadata, SIO protocol 9/10
selection, safer live-DCP handoff and upstream firmware-27 groundwork. The
M3 external DCP remains disabled on the current 14.7 firmware because it
crashes the primary DCP. ROM3's J613 audio fix is included and all 47 audio
scenarios pass. See the
[`stable-20261124.2` release notes](https://github.com/adrgu372/ROM3-j613/releases/tag/stable-20261124.2)
for the complete J613 summary.

This release is marked as a prerelease only so it cannot replace the stable
snapshot behind `releases/latest/download`. Its packages and database are
fully signed and qualified.

The corresponding Linux, Aura and ROM3 source bundles are attached to both
this release and `stable-20261124.2`.

## Update

```bash
sudo pacman -Sy
sudo pacman -S --needed rom3-j613-guard rom3-j613-release

sudo rom3-j613-override configure \
  --feed https://github.com/adrgu372/ROM3-j613/releases/download/override-20261124.2 \
  --fingerprint FA80FF234BCDF36211649321EB9845C8BAA89A4A

sudo rom3-j613-update --check
sudo rom3-j613-update --apply
```

Reboot and run:

```bash
/usr/share/rom3-j613/verify-live-system.sh
```
