# ROM3-j613 KDE image payload 20261123.1

Filesystem payload for the Aurora Installer `alarm-btrfs-v1` layout, built only
for `apple,j613`.

It uses `stable-20261122.9` and includes:

- automatic re-establishment of ROM3 package-signing trust after the
  machine-local pacman master key is created;
- `rom3-j613-guard 1-6`, including authenticated external override feeds;
- the verified J613 kernel, audio, PipeWire, Aura, Mesa and KWin stack;
- the ROM3 repository, exact meta-package and update guard.

GitHub release limits require the filesystem archive to be split into five
parts. `SHA256SUMS` is signed by the ROM3-j613 project key. The filesystem
archive also has GitHub build provenance available as an offline attestation.

This remains a testing image. It is not evidence of a clean-install, every-boot
or Recovery qualification cycle on J613.
